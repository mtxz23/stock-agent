# 观研

一个在本机运行的对话助手。你可以直接聊天、讨论问题，也可以让云端模型搜索资料、阅读财报、计算数据并研究公司。

目前支持聊天、公司研究，以及A股基本面、股票、境内外指数和商品的历史行情与基础技术指标查询。持续监控提醒和自动交易尚未实现。

## 启动

在项目目录执行：

~~~powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
~~~

然后打开：http://127.0.0.1:8765

向量数据库管理界面：http://127.0.0.1:6333/dashboard 。启动脚本会先启动本机 Qdrant 独立服务，再启动研究后端。

第一次安装或换电脑时，先按[开发与安装说明](docs/development.md#安装)准备环境。

## 使用

1. 打开“模型连接”，填写 API 地址、模型名称和 API Key，保存并测试。模型需要支持工具调用。
2. 点击“新对话”，选择模型，直接输入消息。例如“你好”“解释一下利润率”或“帮我研究阿里巴巴”。
3. 回复按对话显示。展开“处理过程”查看模型做了什么；读取过原文时，可以在“原文来源”核查资料或下载原文。
4. 打开“长期记忆”，在条目列表中添加、编辑或删除内容。系统也会自行整理记忆，保存后可跨新对话、跨模型使用。
5. 在底部继续发消息，也可以换一个模型。处理中可以停止，停止或失败后可继续上条回复或发送新消息。

新对话会先显示首条提问作为临时标题；每次回复完成后，系统根据前 3 次提问在后台生成或完善简短标题，卡片会自动更新。第 4 次起不再自动改名。你手动改名后，系统会一直保留你的标题；已有对话也保持原名。自动命名最多额外发起 3 次简短模型请求，失败时保留当前标题，不影响回复。

点击左侧“最近对话”卡片右上角的“⋯”，可以重命名或删除整段对话。有多条提问时，菜单中的“查看提问”会打开独立列表，支持关键词搜索；点击一条提问，会恢复它所在的完整分支并定位、标出原消息，后续消息仍可向下滚动查看。在当前分支内定位只改变阅读位置，继续发送时仍接在最新消息之后。新标题会同步到所有提问和分支，后续消息继承该标题；原始提问不变。删除需要确认，会先停止这段对话正在处理的回复，再删除所有提问、报告、处理记录、检查点及原文归档，删除后无法恢复。独立保存的长期记忆会保留，可在“长期记忆”中另外删除。

系统在后台自动同步同花顺远航版的自选和分组，保存到本地数据库，不设置单独的自选页面。系统自动发现本机安装目录，每 10 秒检查缓存变化，浏览器关闭时仍会同步；你无需手动导出。可以直接在对话里问“我的自选有哪些？”或“近期关注分组里有哪些股票？”，AI 会调用工具查询。名称优先使用本地实时、基础字典；常用指数有离线名称回退，其余缺失名称尝试从公开服务按市场和代码补全并缓存，断网保留已取得名称。自选不等于持仓，也不包含实时行情和财务数据。手机端修改需要先由同花顺同步到电脑端；查询工具返回缓存和系统同步时间，读取失败保留上次结果并说明限制。

股票基本面由东方财富公开F10提供，包含公司概况、主营、财务指标和三张完整报表；股票及指数、商品行情由腾讯和新浪公开接口提供，不需要新增付费账户。可直接问“查贵州茅台最近四期营收”“今天市场行情怎么样”“多晶硅、生猪、碳酸锂期货最近走势如何”“纽约金和布伦特原油价格怎么样”。

行情支持原有国内指数、11个境外指数、29种国内商品期货及纽约金、白银、布伦特、WTI、天然气和伦敦金现货，提供日／周／月行情和基础技术指标。国内商品可查询连续及具体月份合约；结果注明价格单位、收盘／结算价、来源交易日期、市场时区和异常／缺失。连续换月未经核实，不据此生成突破信号；ETF与海外公司基本面未接入，纳斯达克100因来源身份异常暂未启用。[完整品种与口径说明](docs/market-data.md)。

工具返回来源和实际范围，缺失值不填零，断网注明旧缓存。模型使用的数据及原始响应归档到对话来源中，结构化数据不能替代重大结论所需的公告原文。

Enter 发送，Shift+Enter 换行。关闭网页后，后台研究仍会继续；关闭后端服务会中断研究。

普通聊天直接回答，需要调查公司时由模型识别研究对象，不明确就先询问。后续消息会带上当前分支的近期对话和必要摘要；较早内容过长时自动压缩，原记录仍保留。新问题首次分析前自动按语义找回相关历史，普通寒暄会跳过；模型还可以通过工具补查和读取原文。检索模型可在“模型连接”的“历史向量检索”中设置，默认复用已有连接。“处理过程”可查看自动召回的片段、压缩摘要和历史工具结果。长期记忆全部带入。研究报告中的事实和判断仍需结合原文核查。

## 数据在哪里

- `data/`：研究记录、长期记忆、自选快照、股票数据缓存、报告、模型连接和已读取的原文；`data/qdrant/storage/` 保存独立服务的历史向量索引，原 `data/vectors/` 保留迁移前的数据。
- `logs/`：运行日志与请求诊断，按日期分文件保存。

换电脑时，关闭服务后备份整个 `data/` 目录，保留其中的密钥文件。

安装、代码结构、日志查询和检查命令见[开发说明](docs/development.md)。

提示词、请求结构与工具机制见[系统核心机制](策略.txt)。
